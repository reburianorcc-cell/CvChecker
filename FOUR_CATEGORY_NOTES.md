# Automatic four-category evaluation

The same original six-criteria weighted score is evaluated for all four categories. Key International: 70%; Key National: 50%; Non-Key International: 50%; Non-Key National: 50%. The latter three reuse the original existing 50% threshold, **not separately validated TOR eligibility rules**. Non-Key shows PASS/FAIL without percentages. Key shows percentage. Historical records also display the four outcomes when opened. No new database columns are needed.
